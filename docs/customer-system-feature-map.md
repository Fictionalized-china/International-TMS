# 客户现有汽运系统功能映射

## 订单中心

- 大表格查看订单、工作号、委托人、业务类型、线路、人员、日期和审批状态。
- 组合条件搜索、状态快捷筛选、排序、分页、导出和批量操作。
- 点击订单进入订单中心；订单总体进度由已启用子模块汇总。

## 委托信息

- 委托人、委托号、业务来源、业务性质、业务类型、RO 代理、工厂、货好时间。
- 运输条款、贸易条款、合同号、委托服务。
- 发货人、收货人、起运地、中转地、目的地、交货地、口岸、清关地和线路说明。
- 委托提交、主管审核和审核记录。

## 货物信息

- 多条最小货品记录；中英文品名、境内外 HS Code、品牌型号、原产国、唛头。
- 包装类型、包装数量、每包装件数、毛重、净重、尺寸、体积和申报货值。
- 危险品、带电、液体、磁性等特殊属性以及多张货物图片。
- 自动汇总总件数、总重量、总体积，并生成最小包装编号。

## 任务分配

- 为跟单、仓库、报关、单证、配载、运踪、客服、商务和财务分配负责人及期限。
- 记录待办、转派、完成、超时和操作历史。

## 仓库作业

- 到仓收货、扫描、验货、称重量方、图片凭证、库位、库存、移库和盘点。
- 分拣、集货、齐套复核、装车出库和车辆交接。

## 报关作业

- 起运地报关和目的地清关分别管理。
- 报关方式、单证提供方、报关/清关行、联系方式、截关、申报和放行日期。
- 转关、查验、报检及说明；报关单号、改单、删单重报和状态。

## 文件单证

- 上传、下载、预览、文件日志、分类、说明、客户公开标记和审核状态。
- 委托资料、报关清关、运输单证、运单、发票费用和签收凭证分类归档。

## 运输执行

- 头程、干线、后程分别安排承运商、车型、车辆、司机和司机证件。
- 起运地、目的地、口岸、中转地、路线国家、计划/实际发到时间、运费和装载要求。
- 订舱作为业务节点分批记录。
- 运单维护发货人、收货人、地址、发货人指示、海关记载、随附单证及核对状态。

## 拼车配载

- 待配载池按线路、委托人、承运商、仓库、公司、负责人和时间筛选。
- 人工组车并实时汇总重量、体积；校验车辆载重、容积和资料完整性。
- 同一批货可按最小包装分到不同车辆，每个包装在同一批次不得重复配载。
- 配载单可维护车辆、司机、状态、装载要求并执行发车复核。

## 运输跟踪

- 实际发车、到达口岸、出境、换装、转关、国外入境、到站、清关、派送、签收和完成。
- 记录时间、地点、车辆、说明以及是否同步客户门户。

## 费用结算

- 应收与应付分区；费用名称、往来单位、币种、汇率、计费单位、数量、单价和金额。
- 税率、税金、发生日期、内部费用、国外账单号和费用备注。
- 预估利润、费用审核、发票、收付款、对账、业务锁定和财务锁定。

## 异常处理

- 资料、货物、仓库、报关、配载、运输和费用异常统一登记。
- 严重等级、负责人、处理期限、图片证据、冻结、处理进展、客户可见范围和结案。
