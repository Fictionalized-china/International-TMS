# 老板全流程代办与岗位协作

## 交付目标与边界

- 老板保持自己的账号和审计身份，能够代办各内部岗位已经开放的业务。
- 原岗位的责任人、通知、数据范围及工作流配置继续保留，不为普通账号增加权限。
- 老板代办只跨越岗位、负责人限制，不跳过必填资料、节点先后、扫码、单据审批、收付款金额、核销及最终归档条件。
- 已完成或取消的订单保持只读；本次不恢复、重置或伪造线上业务数据。
- 客户门户仍按真实客户身份隔离，不以老板冒充客户；境外仓自提签收沿用仓库的真实办理入口。

## 修正内容

1. 审核入口使用与后台一致的老板代办规则：已提交订单不再仅向原指定操作主管显示审核按钮。
2. 工作流人工任务按钮复用后台共享的负责人判断，老板可代办，未来节点、系统自动完成任务及结束订单不开放跳过按钮。
3. 老板的在办订单筛选包含全部未结束订单，不因原责任人不是老板而隐藏；公司级数据范围不再被岗位门户的个人范围设置收窄。
4. 订单内仓库相关模块提供“以老板身份进入办理”，仓库管理提供逐仓入口。
5. 复用既有 `/switch-site` 入口，创建老板自己的仓库站点会话；保留窗口标识、订单及实际仓库，不切换成员工身份。仓库端新增老板切仓及返回管理端按钮。
6. 切仓校验启用仓库、组织边界与当前身份；普通仓库账号不可使用老板跨仓入口。
7. 一并发布此前已修复的出纳重复登记提示、既有流水展示及正金额核销建议。已登记的供应商付款应核对现有流水后核销，不再重复付款。

## 使用方式

### 老板单账号演示

1. 老板登录管理端，从订单中心直接录单。
2. 正常选择业务责任人并完成“审核分配”；责任人仍可保留原岗位人员，老板不需要改成这些员工账号就能代办。
3. 按订单中心当前节点办理国内运输、单证、配载、商务找车、资源确认与运踪；拼车仍先选单生成配载计划，再发送商务落实资源。
4. 仓库节点点击“以老板身份进入办理”，选择本单实际仓库，按原规则收货、扫码、打包或装车出库。也可从“仓库管理”的逐仓按钮进入。
5. 在仓库侧边栏可切换办理仓库，处理莫斯科收货与客户自提签收；“返回管理端”回到订单继续办理。
6. 在订单的费用模块依次完成应收、应付方向的签核，生成并确认对账单，登记真实收付款流水并核销。
7. 财务闭环和其他必办项目全部完成后，再最终复盘归档。

### 原岗位协作

业务员录单 → 操作主管审核分配 → 操作岗办理国内运输并录入实际费用 → 国内仓收货和打包 → 操作主管生成配载计划 → 商务找车并绑定资源 → 操作主管确认 → 仓库装车出库 → 单证/运踪岗按配置办理 → 境外仓收货与客户签收 → 客服/操作/操作主管/财务按应收应付签核配置办理 → 对账确认 → 出纳登记真实收付款并核销 → 财务复盘归档。

以上是导航说明，具体岗位和必办项以订单冻结工作流、业务策略及已指派人员为准，不新增硬编码流程。
