| 关闭资料维护仍能新增陌生资源 | 原找车新增只检查找车办理权 | 另查 `carrier.manage`，无权隐藏新增选项；保留按授权绑定现有资源 |
| 费用及同类工作台在 MySQL 报 500 | 公用查询名 `rows` 冲突 MySQL 保留字 | 改为 `workbench_rows`，覆盖任务、文件、报关、运踪、费用五类，补充五组回归 |

## 配置与业务边界

- 菜单开关、读取权、办理权及数据范围分别保留，不以隐藏菜单代替服务端授权。新增权限纳入原岗位/账号配置，本次迁移只修复旧默认值，管理员以后仍可重新授权。
- 找车启停、办理岗位仍由业务策略决定，不绑定唯一账号。老板/开发者能力保留。
- 拼车业务不变：主管选单成批 → 发送商务 → 商务绑定资源 → 主管确认 → 仓库装车。筛选只作用于已授权且已符合待配载条件的候选，最终提交仍校验同仓、同目的仓、状态、冻结工作流和并发条件。
