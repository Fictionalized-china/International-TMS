# 整车全流程权限与门禁查验（2026-09-05）

## 查验结论

本次按整车业务主链路逐段检查了页面入口、服务端授权、状态前置条件、数据写入和下一节点同步：

> 报价确认 → 委托资料补充后提请审批 → 审批 → 任务分配 → 国内运输 → 国内仓入库 → 创建装车任务 → 整车装车出库 → 报关放行 → 实际出境及运踪 → 境外仓入库 → 客户自提签收 → 三方结算 → 复盘归档

代码级查验未发现仍会令整车主链路无合法下一步的阻断。查验期间定位并修复了三个生产风险：

1. 业务员提交审批错误依赖订单当前处理人，历史/迁移订单会被误判为无权提交；现改为严格校验订单绑定业务员。
2. “到达出境口岸”曾提前把整车批次写成“已实际出境”；现只有明确登记“出境”才写实际出境时间并开放境外段。
3. 费用三方确认接口曾只依赖页面隐藏，理论上可在自提前绕过页面提交；现服务端强制要求订单已经进入“对账结算”节点。

## 全流程角色与门禁矩阵

| 业务节点 | 合法办理人 | 服务端关键门禁 | 成功后的下一步 |
| --- | --- | --- | --- |
| 委托资料补充、提请审批 | 订单绑定业务员 | 草稿状态；绑定业务员本人；模板必填字段和必需委托文件齐全；下一处理人必须是有效业务主管 | 状态变为待审批，当前处理人切换到指定业务主管 |
| 委托审批 | 指定业务主管 | 当前处理人精确匹配；委托书已审核；下一处理人必须是有效操作主管 | 状态变为待派单，记录操作主管 |
| 任务分配 | 指定操作主管 | 订单为待派单；操作、单证、客服、财务四类具体个人账号均有效；各模块负责人写入后再原子推进 | 状态变为执行中，先进入国内运输 |
| 国内运输 | 指定操作岗 | 运输模块归属本人；国内承运商、车辆、司机、线路及预计应付按工作流要求齐全 | 生成/更新首程运输安排和运单，等待国内仓收货 |
| 国内仓入库 | 当前国内仓被授权仓库人员 | 仓库归属；订单/运单匹配；实收件重体、库位、标签、凭证和异常结果按模板校验 | 确认货齐后关闭国内运输，开放装车出库 |
| 创建整车装车任务 | 当前国内仓被授权仓库人员 | 必需发运文件已上传并确认；口岸/清关地为有效基础数据；出境承运商、车辆、司机和计划时间有效；仓库货齐且无阻断 | 建立一票一车主运输安排和装车任务 |
| 整车装车出库 | 当前国内仓被授权仓库人员 | 车辆与线路再次校验；逐件扫码按模板必填或二次确认差异；所有货物属于当前任务 | 装车模块完成，进入起运地报关 |
| 报关放行 | 指定单证岗 | 单证模块归属本人；必需报关文件已审核；至少一张有效起运地报关单且全部放行 | 报关模块完成，当前处理人切换到操作岗运踪 |
| 实际出境及运踪 | 指定操作岗 | 节点顺序校验；到达口岸前重验装车、文件、放行和车辆；只有“出境”节点记录实际出境 | 批次进入出境运输，按国外入境、目的地清关继续推进 |
| 境外仓入库 | 订单指定境外仓的被授权仓库人员 | 已明确实际出境；仓库精确匹配；公司代办清关时须先完成目的地清关；必须扫描国内仓原标签 | 货齐后完成运踪并自动通知客户 |
| 客户自提签收 | 订单指定境外仓的被授权仓库人员 | 客户已通知/已预约；全部货物逐件扫描；无异常货物 | 境外仓模块完成，生成应收对账待办并进入对账结算 |
| 三方费用确认 | 指定客服、订单绑定业务员、指定财务 | 服务端要求当前为对账结算节点；两方向均有有效费用及往来单位；三方按具体个人账号独立签核；并发重复提交受影响行数保护 | 应收、应付均完成三方签核后进入复盘 |
| 对账、收付款与核销 | 有结算权限的财务/出纳 | 仅确认费用可入对账；应收须已实际出境；同方向、同往来单位、同币种；核销不能超过余额 | 更新费用结算状态和复盘阻断项 |
| 复盘归档 | 指定财务复盘负责人 | 自提已完成；应收应付存在且三方签核完成；收付款余额为零；仓库差异已确认；无未关闭阻断异常；复盘必填项齐全 | 订单标记已完成并结清；未结清时保留跟进任务，不伪造完成 |

## 整车出境状态修正

整车批次现在按以下状态推进：

| 运踪动作 | 批次路运状态 | 是否写入实际出境时间 | 境外仓是否可收货 |
| --- | --- | --- | --- |
| 到达出境口岸 | `loaded_waiting_exit` | 否 | 否 |
| 出境 | `outbound_in_transit` | 是 | 是（仍受目的地清关门禁约束） |
| 国外入境/目的地清关 | `outbound_in_transit` | 保留首次出境时间 | 是 |
| 境外仓扫码入库并货齐 | `overseas_arrived` | 保留 | 已完成入库 |

迟到或重复的“到达出境口岸”请求不会把已经出境/到仓的批次回退，也不会覆盖首次实际出境时间。

## 拼车配载职责修正

- PZ 配载单由操作主管作为一个整体审批，同时选择一名操作岗和一名单证岗。
- 两个负责人一次性接管配载单内所有订单的运踪/异常及文件/报关模块。
- 原订单操作、单证的活动任务解除；历史任务与操作记录保留为只读审计证据。
- 创建拼车装车任务必须同时满足：PZ 已审批、操作负责人已分配、单证负责人已分配。
- 实际出境前允许操作主管重新分配；实际出境后仅老板/开发者可带原因执行例外改派。
- 到达境外仓后，PZ 操作和单证职责转为只读；订单继续由原客服和财务完成结算与复盘。
