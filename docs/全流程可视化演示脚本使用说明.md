# 全流程可视化演示脚本

仓库根目录提供两个互相独立的启动入口：

- `演示-整车全流程.cmd`：新建并走完 1 票整车订单。
- `演示-拼车配载全流程.cmd`：新建 3 票拼车订单，组成 1 张 PZ 配载单并走完全流程。

## 使用方法

1. 先启动本地 TMS，确认 `http://127.0.0.1:5189` 可以正常访问。
2. 关闭会干扰演示的 Chrome 窗口，不要同时运行两个演示脚本。
3. 双击所需的 `.cmd` 文件。
4. 首次运行会要求选择测试账号 Markdown 文件；账号只在本次进程内读取，不写入报告。
5. 脚本会打开可见的 Google Chrome，并在每次岗位切换前将对应页面带到前台。终端同步显示当前岗位、账号和即将执行的动作。
6. 成功或阻断后，按终端提示查看 `output/playwright/visual-demo-*` 下的截图、追踪和阶段交接文件。

## 安全边界

- 所有业务数据创建和推进只通过可见页面控件、键盘输入及系统原生文件选择器完成。
- 演示脚本不执行 SQL、迁移、种子脚本，也不调用业务写入 API。
- 脚本会创建真实的本地测试订单，请勿连接生产环境运行。
- 任一阶段遇到真实门禁或页面错误会立即停止，不会跳过或直接修改数据继续。

## 演示中的岗位协作

脚本按业务节点依次切换业务岗、业务主管、操作主管、操作岗、单证岗、国内仓、境外仓、客服、财务及客户门户。拼车脚本在生成 PZ 后改由配载单的新操作负责人和新单证负责人继续办理挂载订单。
