# 本地会议流程人工验收清单

日期：2026-10-05。仅使用本地测试环境和专门建立的测试订单；不要以生产真实订单做推进测试。

本地入口：http://127.0.0.1:5189 。本清单不是“已完成”的人工验收记录。

## 录单与职责

- [ ] 业务员从订单中心直接录单，不必先向客户发送报价；当前标准流程不出现业务主管审批。
- [ ] 整车缺任一启用必录费用不能开单；六类费用与应收/应付方向提示明确。拼车提货费留空不能开单，客户自送显式填 0 可开单。
- [ ] 普通客户不能由客服代录；勾选客服代录客户后允许，取消后新录单拒绝。人事协助必须有原因，关闭策略后不再允许。
- [ ] 操作主管可以审核并分派操作、单证、客服、财务个人；非指定办理人不能冒办。老板看到全公司数据不等于代替全部指定人签核。
- [ ] 操作接手后可增加包装等费用；单证和运踪岗位不能因此编辑业务岗专属委托资料或费用。
- [ ] 连续双击或网络重试直接录单，最终只生成一张订单；失败后原内容可纠正，不靠改单掩盖问题。

## 运踪、商务与配载

- [ ] 运踪岗从提货开始可多次填地点、时间、说明和车号；同一天同状态可以多条记录；客户可见记录在客户门户轨迹出现，内部记录不泄漏。
- [ ] 每日运踪记录不能冒充报关放行、实际出境、仓库入库或客户签收，不跳结构节点。
- [ ] 资料齐全且预计到口岸时间填写后出现商务找车任务；同单重复触发不重复任务或通知。缺项提示能定位缺少字段。
- [ ] 商务只录入同一有效供应商所属车辆和司机；反馈成本币种汇率可保存；无成本查看权的其他岗位看不到成本金额。
- [ ] 操作主管用已知运输资源勾选两票拼车生成配载；无需仓库自审批。子订单应付按配置分摊，默认抛重比 1:300，合计与整批成本一致。
- [ ] 费用锁定、订单不符或资源失效时整批不保存，不出现部分订单挂载或部分应付。重复创建返回同一批次。
- [ ] 仓库接手后按原验收、打包贴标、扫码、装车出库流程执行；管理端规划成本不能绕过仓库实体出库。
- [ ] 相同重量体积不误报异常；未清点的实际件数和尺寸仍显示为空或未清点，不编造为 0。已有仓库回归通过仍需界面确认。
- [ ] 超时/异常能在工作台或运踪总览看到；业务和操作收到通知，同日重扫不重复弹出；停用预警保留旧记录。

## 应收、应付、核销、人事

- [ ] 实际出境前不能费用签核；出境后无须客户自提即能开始应收链，运输继续执行。
- [ ] 业务/特定客服→操作→操作主管按当前启用必办步骤签核；任何人不能越级代签，也不因第一人点确认就完成整个结算节点。
- [ ] 客服可生成已确认应收对账单，其他未获授权岗位不能生成；缺应付提示补录，不强行堵住独立应收通道。
- [ ] 应付按操作/商务申请→主管→财务→线下总经理审批记录→出纳办理；关闭线下记录要求按配置生效，不抹掉已有审批记录。
- [ ] 未审批、申请币种/往来不匹配、超额度付款被拒绝；重复流水登记不出现第二笔记录。
- [ ] 核销 50 后重复提交原请求仍只核销 50；下一次明确新请求才能继续核销。余额变化被安全拒绝，未发生负余额或重复占用。
- [ ] 出纳首页出现已审批待付款，点击直接到对应收付款页签。客服待出单跳到待对账页签。
- [ ] 人事列表只包含全部实际回款订单；部分回款不进入；未确认成本不算正式毛利。相同姓名不同账号分别汇总。
- [ ] 人事可登记提成、发放状态、日期与备注；修改保留版本历史，刷新旧版本保存时给冲突提示；未全回款订单的直接请求也被拒绝。
- [ ] 周/月报、主车换装车号、拼车发车去重、导出在不同账号权限下口径一致；撤销金额查看权后页面和导出都隐藏敏感金额。

## 配置、界面与历史

- [ ] 新增必填自定义字段在当前指定岗位出现输入框，服务端同样使用字段级权限；隐藏字段不显示不阻断。
- [ ] 当前/未来节点采用新配置，已通过节点仍按历史显示；全部审批字段隐藏或空配置不产生无法填写的必填项。
- [ ] 停用找车、每日运踪、人事报表等，只停止新增/办理，不删除历史；重新启用仍能查看原记录。
- [ ] 一般电脑宽度筛选控件对齐，高级条件收起后不占大块；小屏允许合理换行而非硬挤一行。
- [ ] 单个分析页签只出现所属内容，金额权限不同不出现空的可编辑表单；不可办操作有清晰原因和下一步入口。
- [ ] 本单、跨单、拼车拆分后订单、客户唛头页、配载查看等只读页面无恢复错误页；这项需真实浏览器登录逐项确认。

- [ ] 菜单去重方案另行确认，入口变化后所有旧链接、权限、关键动作与配置能力均可用。
