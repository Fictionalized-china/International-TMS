# 岗位权限与门户

岗位门户解决“登录后先去哪里”的问题，模块权限解决“进入页面后能做什么”的问题。老板和超级管理员可查看、操作全部业务；其余岗位只显示与职责相关的入口和待办。

| 岗位 | 默认查看范围 | 可操作范围 | 门户主要入口 |
| --- | --- | --- | --- |
| 老板 | 全部订单、经营、利润、费用、客户、流程和审计 | 审批派单、重大异常、费用复核、流程与权限配置 | 经营总览、订单、费用、工作流、审计 |
| 开发者 | 工作流、基础数据、岗位权限、审计 | 流程模板、节点字段、主数据和系统配置 | 工作流、基础数据、岗位、角色 |
| 单证 | 本人订单、文件、报关、运输节点 | 上传审核文件、多报关单、海关审核和放行 | 单证待办、报关待办、运单 |
| 客服 | 客户、本人订单、轨迹、费用状态 | 委托货物、客户可见轨迹、客户异常、费用预录 | 我的待办、客户、运踪 |
| 财务 | 订单摘要、应收应付、利润、审计 | 费用审核锁定、对账、开票、收付款、核销 | 费用待办、结算、审计 |
| 业务员 | 本人客户、销售报价、本人订单 | 客户、报价、订单、委托货物、应收预估 | 客户、报价、订单 |
| 海外人员 | 出境后订单、境外轨迹、目的仓、海外异常 | 境外轨迹、到仓、通知、预约和提货 | 海外待办、运踪、运单 |
| 箱管 | 待到仓、实收、待配载、批次车辆 | 收货复核、齐套、组批、装车出库 | 仓库待办、拼车配载、订单 |
| 业务助理 | 客户、协作订单、报价摘要、费用状态 | 客户、订单、货物、费用预录 | 客户、订单、待办 |
| 操作 | 全部执行订单和执行模块 | 审批派单、国内运输、仓配、单证报关、运踪、异常 | 业务待办、订单、运单、配载 |
| 商务/航线 | 承运商、线路、运输需求、配载成本 | 承运商、线路产品、运输配载方案、成本 | 承运商、物流产品、配载 |
| 订舱人员 | 订单、承运商、运输安排、运单和发运文件 | 运输订舱、运单、配载协助和文件核对 | 运输待办、运单、承运商 |

## 权限原则

1. 岗位门户只展示岗位相关入口和当前待办，不复制业务数据。
2. 订单模块页可被授权人员查看，但只有具备该模块操作权限的账号显示提交按钮。
3. 未来阶段的模块保持只读且隐藏业务表单，进入对应阶段后自动开放。
4. 老板和 `owner` 超级管理员拥有全部模块操作权限。
5. 工作流模板和字段积木仅老板、开发者和超级管理员可编辑。
